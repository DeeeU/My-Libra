# サブスクリプション設計書

## 1. 概要

My-Libra に Free/Pro の2段階プランを導入し、StoreKit 2 による Auto-Renewable Subscription で収益化する。

### 1.1 前提条件
- `feature/account-supabase`（認証 + クラウド同期）がmainにマージ済みであること
- iOS 17.0+ (StoreKit 2 対応)

### 1.2 課金モデル
- **Auto-Renewable Subscription** (自動更新サブスクリプション)
- 月額プラン / 年額プラン（年額は約34%割引）
- 7日間の無料トライアル期間

### 1.3 Product ID
| プラン | Product ID | 価格（予定） |
|--------|-----------|-------------|
| 月額 | `com.deeu.mylibra.pro.monthly` | ¥150/月 |
| 年額 | `com.deeu.mylibra.pro.yearly` | ¥1,500/年 |

## 2. Free / Pro 機能分割

| 機能 | Free | Pro | ゲーティング方式 |
|------|------|-----|----------------|
| 買い物リスト | 無制限 | 無制限 | なし（コア機能） |
| アイテム登録 | **25件まで** | 無制限 | 新規追加時にカウントチェック |
| 写真 | なし | あり | 写真セクション非表示 |
| カスタムカテゴリ | プリセット7種のみ | 追加/編集/削除 | CRUD操作を制限 |
| 統計 | ロック表示 | 全機能 | ビューにオーバーレイ |
| CSVエクスポート | なし | あり | ボタン無効化 |
| クラウド同期 | なし（ローカルのみ） | あり | 同期トリガーをガード |
| 損益表示 | 売却記録のみ | + 利益計算表示 | 利益行を非表示 |

### 2.1 ダウングレードポリシー
- 既存データは**一切削除しない**
- 25件を超えるアイテムは**閲覧・編集可能**、新規追加のみ不可
- 既存の写真は**表示可能**、新規追加のみ不可
- 既存のカスタムカテゴリは**使用可能**、新規追加・編集のみ不可

## 3. アーキテクチャ

### 3.1 全体構成

```
┌──────────────────────────────────────┐
│  UI Layer (Views)                     │
│  - PaywallView (購入画面)             │
│  - UpgradePromptView (導線)           │
│  - 各ビューの canAccess() チェック      │
├──────────────────────────────────────┤
│  PlanManager (@Observable singleton)  │  ← 中核
│  - isPro: Bool                        │
│  - canAccess(_ feature:) -> Bool      │
│  - canAddItem(currentCount:) -> Bool  │
├──────────────────────────────────────┤
│  StoreKitService                      │
│  - Product ロード                      │
│  - Purchase / Restore                 │
│  - Transaction リスナー               │
│  - Entitlement 確認                   │
├──────────────────────────────────────┤
│  UserDefaults (キャッシュ)              │
│  - オフライン時のPro状態保持            │
└──────────────────────────────────────┘
```

### 3.2 ProFeature 定義

```swift
enum ProFeature: String, CaseIterable {
    case unlimitedItems       // 25件超のアイテム登録
    case photos               // 写真添付
    case customCategories     // カスタムカテゴリ追加/編集/削除
    case statistics           // 統計タブ
    case csvExport            // CSVエクスポート
    case cloudSync            // クラウド同期
    case profitDisplay        // 損益表示
}
```

### 3.3 PlanManager

```swift
@MainActor @Observable
final class PlanManager {
    static let shared = PlanManager()

    var isPro: Bool           // StoreKit entitlement || UserDefaultsキャッシュ
    func canAccess(_ feature: ProFeature) -> Bool
    func canAddItem(currentCount: Int) -> Bool  // currentCount < 25 || isPro
    func purchase(_ product: Product) async throws
    func restorePurchases() async
}
```

- `@Environment(PlanManager.self)` で全ビューからアクセス
- `SupabaseManager.shared` と同じシングルトンパターンを踏襲

### 3.4 StoreKitService

```swift
@Observable
final class StoreKitService {
    func loadProducts() async                          // App Store Connect から商品取得
    func purchase(_ product: Product) async throws     // 購入処理
    func restorePurchases() async                      // 購入復元
    func updateCurrentEntitlements() async             // 有効な課金確認
    private func listenForTransactions() -> Task       // リアルタイム更新リスナー
}
```

- `Transaction.currentEntitlements` で有効なサブスクを確認
- `Transaction.updates` でリアルタイム更新（更新/期限切れ/取消）を監視

### 3.5 オフライン対応
- `UserDefaults` に `cachedProStatus: Bool` を保持
- StoreKit 状態変更時に同期
- オフライン時はキャッシュを参照してPro機能を維持

## 4. UI コンポーネント

### 4.1 PaywallView（ペイウォール）

フルスクリーンのモーダルシート。以下を表示:
- アプリアイコン + "Pro にアップグレード" ヘッダー
- 機能比較テーブル（Free vs Pro）
- 月額/年額のトグル選択
- 年額には "17%お得" バッジ
- "7日間無料で試す" 表示（トライアル期間中）
- 購入ボタン
- "購入を復元" リンク
- 利用規約・プライバシーポリシーリンク（**Apple審査要件**）
- サブスクリプション条件の明示（**Apple審査要件**）

### 4.2 UpgradePromptView（インライン導線）

各ゲーティングポイントで表示する軽量コンポーネント:
- 王冠アイコン（crown.fill）
- 機能ごとのロック説明メッセージ
- "Pro にアップグレード" ボタン → PaywallView を表示

### 4.3 SubscriptionManagementView（設定内）

SettingsView のサブビュー:
- 現在のプラン表示（Free / Pro Monthly / Pro Yearly）
- Pro の場合：有効期限表示
- "Pro にアップグレード" ボタン（Free の場合）
- "購入を復元" ボタン
- Apple サブスクリプション管理画面へのリンク

## 5. ゲーティング実装パターン

全ビューで統一パターンを使用:

```swift
struct SomeView: View {
    @Environment(PlanManager.self) private var planManager
    @State private var showPaywall = false

    var body: some View {
        // 制限チェック
        Button("制限機能") {
            if planManager.canAccess(.someFeature) {
                // 通常処理
            } else {
                showPaywall = true
            }
        }
        .sheet(isPresented: $showPaywall) {
            PaywallView()
        }
    }
}
```

### 5.1 各ビューのゲーティング詳細

| ビュー | 対象 | 方式 |
|--------|------|------|
| OwnedItemsView | 新規アイテム追加ボタン | `canAddItem(currentCount:)` チェック |
| WishlistView | 「購入」スワイプアクション | 同上 |
| EditItemView | 写真セクション | `canAccess(.photos)` で表示/非表示 |
| PurchaseDetailView | 写真セクション | 同上 |
| ItemDetailView | 利益/損失表示行 | `canAccess(.profitDisplay)` |
| StatisticsView | ビュー全体 | オーバーレイでロック表示 |
| CategoryManagementView | 追加/編集/削除 | `canAccess(.customCategories)` |
| SettingsView | CSVエクスポートボタン | `canAccess(.csvExport)` |
| AuthGateView | 同期トリガー | `canAccess(.cloudSync)` |
| SyncCoordinator | `performSync()` | 安全ネットとしてガード追加 |

## 6. Apple 審査要件

### 6.1 必須表示事項
- サブスクリプション価格（月額・年額）
- 自動更新であること
- 無料トライアル期間と終了後の課金
- キャンセル方法
- 利用規約リンク
- プライバシーポリシーリンク

### 6.2 アプリ審査ガイドライン準拠
- [3.1.2(a)](https://developer.apple.com/app-store/review/guidelines/#subscriptions): サブスクの条件を明記
- 購入前にユーザーが内容を理解できるUI
- "購入を復元" 機能の提供
